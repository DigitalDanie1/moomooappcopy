# Moomooapp

Static fullscreen mobile prototype for a class/demo app flow.

The project is a local-first PWA shell that shows one intro screen and then switches between prepared screen images through transparent tap zones. It has no login flow, backend, payment, trading, account access, or data collection.

## Files

- `index.html` - fullscreen app shell and tap-zone routing
- `intro-screen.png` - first screen
- `app-screen.png` - Accounts screen
- `screens/` - tab/article screens
- `manifest.json` - installable PWA metadata
- `service-worker.js` - offline cache for static assets
